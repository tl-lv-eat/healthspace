# 日历 ↔ 计划联动

**Status:** implemented

## 方案

计划挂在日历下方卡片列表，可新建/编辑/删除。每条计划自选：

- **开始日期 / 结束日期**（含首尾，最长 60 天）
- 日饮水目标 ml
- **期间热量缺口** kcal（均摊到区间天数作日参考）
- **期间运动次数**（这段日子练几天，不必每天）
- 可选体重目标 kg

某日历日取「覆盖该日」的计划（有重叠时取开始日最新的）；无覆盖则用默认饮水 / 默认缺口。

日色块（双方上下半格）：

- **绿 full**：饮水达标 **且** `摄入 − 运动消耗 − BMR ≤ 0`（无热量盈余）
- **黄 partial**：两项只达成一项
- **灰 none**：两项都未达成，或全日未记

BMR：Mifflin–St Jeor；体重/身高取最近身体记录，否则用默认档案。运动消耗：有氧约 7kcal/分；力量按次数粗估。

顶部进度条：当前覆盖「今天」的计划区间内，累计缺口贡献 / 期间缺口目标；已运动天数 / 期间运动次数。

日志 Tab 已合并进日历（旧 `/journal` 重定向到日历）。
