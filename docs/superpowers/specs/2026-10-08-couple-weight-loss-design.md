# 情侣双人减肥记录应用 — 设计规格

**日期：** 2026-10-08  
**状态：** 已评审（对话确认）  
**产品暂定名：** 双人减  

## 1. 目标与约束

面向固定情侣两人的私用减肥/健康记录 Web 应用（手机优先 H5），可联网同步。不公开发布、不做多租户。

**已定约束**

- 形态：H5 / 轻量 Web（非微信小程序原生）；本机开发完成后可迁到公网云主机。
- 账号：固定两人 — 展示名 🐉（男）、🍃（女）；无注册、无邀请码。
- 后端：Python FastAPI + SQLite；复用现有 `call_llm.py` 的 Maas（联网）调用。
- 前端：Vue3 + Vite 手机 H5，基于开源脚手架（推荐 vue3-vant-mobile）+ Vant + ECharts；动作示范用 ExerciseGymGifsDB（GIF + 说明，加中文映射）。
- LLM：统一用百炼 `qwen3.8-27b`（或 `qwen3.6-27b`）。二者均为原生视觉语言模型，文本聊天与饮食看图共用同一模型；看图时消息带 `image_url` + 文本（现有 `call_llm.py` 需扩展多模态消息格式）。

**成功标准（分期见 §8）**

两人能各自完成「饮食 / 饮水 / 运动」日记录，在日历上对比完成色块，有周计划与目标积分奖励，并能收到微信侧提醒（PushPlus）；AI 估卡、日周分析与聊天按期接入。

## 2. 非目标

- 微信小程序原生包、公开上架与审核流程
- 开放注册、多对情侣、社交广场
- 真实支付 / 商城
- 医疗诊断或处方级建议（聊天页脚需免责声明）
- 本期不做复杂离线优先同步

## 3. 信息架构

登录后进入同一情侣空间。底部五个 Tab：

| Tab | 职责 |
|-----|------|
| 今日 | 当日饮食、饮水、运动入口；顶栏双方今日完成摘要 |
| 日历 | 月历色块（上 🐉 / 下 🍃）；点日看详情；编辑当周计划 |
| 日志 | 双方摘要时间线（饮食/饮水/运动完成情况，不堆照片） |
| 目标 | 短/长期目标、积分、奖励兑换 |
| 我的 | 身体数据、趋势对比、AI 聊天入口、PushPlus、账号相关 |

**独立全屏页：** 运动记录、身体数据编辑/对比、AI 日终与周报、智能聊天。

## 4. 系统架构

```
手机浏览器 (Vue3 H5)
        │
        ▼
FastAPI 单进程
  ├─ REST API
  ├─ 托管前端 dist
  ├─ 本地上传目录（饮食照等）
  ├─ call_llm.py（Maas；`qwen3.8-27b` 等 VL 模型，文本+看图）
  ├─ 定时任务（日终/周报、PushPlus）
  └─ SQLite
```

**部署路径：** 本机可跑 → 拷贝到有公网入口的云主机 + 反向代理（HTTPS）；定时任务依赖进程常驻。

**身份与权限：** 配置/环境变量写入两用户及密码；登录后 Session/JWT 标识当前用户。业务行带 `user_id`。可读对方数据；默认不可改对方记录（需切换账号）。

## 5. 数据模型（逻辑）

| 实体 | 说明 |
|------|------|
| users | 固定两账号：内部 id 建议 `dragon` / `leaf`，展示名 🐉 / 🍃，角色、默认饮水目标等 |
| body_metrics | 周记：体重、腰围、体脂、胸围、臀围、身高、备注；派生 BMI |
| daily_logs | 按人按日汇总状态（供日历/日志） |
| meals | 餐次（早/午/晚/加餐）、照片、AI 估卡、用户修正、建议文案 |
| water_entries | 当日多笔饮水 ml，可改删 |
| workouts | 有氧或力量明细 |
| exercise_catalog | 预置 + 自定义动作（中文名、说明、gif_url） |
| week_plans | 当周饮水/饮食/运动完成规则（覆盖默认） |
| goals | 短期/长期目标与进度 |
| rewards | 奖励清单：说明、私密标记、尺度/花费参考、积分价 |
| points_ledger | 积分流水 |
| ai_reports | 日/周分析缓存 |
| chat_messages | 聊天历史（按用户会话） |
| push_bindings | PushPlus token、开关、提醒时段 |

## 6. 功能设计

### 6.1 身体数据

字段：体重、腰围、体脂率、胸围、臀围、身高、备注；BMI 由身高体重计算。频率：约每周一次。双方可查看对比曲线（ECharts）。

### 6.2 今日 — 饮食

- 餐次卡片：早 / 午 / 晚 / 加餐。
- 流程：选餐次 → 拍照/选图 → 多模态返回食物简述、kcal、短建议 → **用户可改 kcal** 后保存；也可无图纯手填。
- 默认「饮食完成」：当日至少 3 次正餐有记录；可由周计划改为其他规则（如任意一餐、总 kcal 区间）。

### 6.3 今日 — 饮水

- 展示已喝 / 目标 ml。目标 = 当周计划值，否则个人默认日目标。
- 快捷加水量 + 自定义；当日条目可改删。
- 完成：已喝 ≥ 目标。

### 6.4 今日 — 运动

- 今日页摘要 + 进入运动全屏页。
- **有氧：** 类型卡片 → 时长（滑块/步进）→ 可选强度 → 保存。
- **力量：** 部位 → 动作卡（GIF + 中文名 + 一句话说明）→ 组数×次数；可连续添加动作。
- 动作库：ExerciseGymGifsDB 精选子集 + 中文映射；支持自定义动作。
- 默认完成：当日 ≥1 条运动；周计划可改为「有氧≥X 分钟」或「力量≥N 组」等。

### 6.5 日历与周计划

- 月视图，日格上下分 🐉 / 🍃。
- 色块反映饮水/饮食/运动相对当周规则的完成度（全达成 / 部分 / 未记）；图例说明。
- 点日 → 当日双方详情。
- 周计划可编辑当周三类规则，保存后重算色块。

### 6.6 日志

按日倒序摘要：饮食是否记、饮水已喝/目标、运动是否完成。筛选：双方 / 仅 🐉 / 仅 🍃。不展示全部饮食照片流。

### 6.7 目标、积分与奖励

- 双方各自短期、长期目标；可互看。
- 与周计划/日完成规则联动发分（规则可配置，如「当日三项全达成 +N」「周计划完成 +M」）。
- 奖励清单可自定义（含私密向，列表可折叠或二次确认）；按尺度与花费感设定积分价。
- 兑奖扣分并标记待兑现/已兑现；无真实支付。

### 6.8 AI

- 看图估卡：**P0 即接入**，同一 `qwen3.8-27b`（或 3.6-27b）传图 → 结构化 JSON（食物简述、kcal、短建议）；用户可改；失败可手填。开发/验收用仓库内 `data/img/` 样例饮食图（当前 2 张）联调。
- 日终分析：默认约 22:00（可配置），基于当日与当周趋势写小结与建议；可手动重试（P3）。
- 周报：周末或周一凌晨生成（P3）。
- 智能聊天：减肥/运动/身体相关问答，注入该用户近期摘要；免责声明（P3）。

### 6.9 提醒

PushPlus（或同类）推到微信。每人在「我的」绑定 token、开关与时刻。仅向未完成项的一方推送。

## 7. 错误处理与降级

- 估卡失败：保留照片，允许手填 kcal，可重试。
- LLM 超时/失败：提示并「再试一次」；不覆盖已有报告为空。
- PushPlus 失败：记日志，设置页可见上次失败；不影响记录。
- 大图：前端压缩；服务端限制大小。
- 改对方数据：拒绝并提示切换账号。

## 8. 分期与验收

| 期 | 范围 | 验收 |
|----|------|------|
| P0 | 双账号登录；饮食（拍照/上传 + **同模型看图估卡** + 用户可改 kcal；失败可手填）；饮水；运动全屏；动作库+GIF；SQLite；本机可跑 | 两人各完成一天完整记录；用 `data/img/` 样例图跑通估卡并人工改数 |
| P1 | 身体周记、对比曲线、日历色块、周计划、日志 | 日历可辨双方达标；点日有详情 |
| P2 | 短长期目标、积分、奖励（含私密）、兑奖 | 规则加分与兑奖闭环 |
| P3 | 日终/周报、AI 聊天、PushPlus | 微信能提醒；AI 报告与聊天可用 |

## 9. 前端开源复用策略

- **脚手架：** vue3-vant-mobile 或 vue-h5-template（Vue3 + Vant + 移动适配）。
- **图表：** ECharts。
- **动作 GIF：** ExerciseGymGifsDB；可选 wger 静态图补充。
- **不整仓 fork** 现成减肥 App（后端/账号模型与双人私用需求不符）。

## 10. 测试策略

以双人手动验收为主。对完成度计算、BMI、积分加减写少量单测。覆盖 LLM/推送失败降级路径。

看图估卡：P0 用 `data/img/` 样例图调用 `qwen3.8-27b`（OpenAI 兼容 `image_url`），断言返回可解析 JSON 且 kcal 可被用户覆盖保存；真机拍照作补充验收。

## 11. 配置要点

- 两用户密码、JWT 密钥
- `llm`：沿用 `call_llm.py` / `config.yaml`（provider=maas，model=`qwen3.8-27b` 或 `qwen3.6-27b`，api_key）
- PushPlus token（每用户）
- 日终/提醒 cron 时刻
- 上传目录路径
